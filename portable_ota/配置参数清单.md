# OTA 必改参数清单

## STM32：`stm32/ota_core/Inc/ota_port_config.h`

| 参数 | 当前 F103 示例值 | 什么时候修改 |
|---|---:|---|
| `OTA_FLASH_BASE` | `0x08000000` | 换 MCU 的 Flash 起始地址 |
| `OTA_FLASH_SIZE_BYTES` | `512*1024` | 按芯片 Flash 容量修改 |
| `OTA_FLASH_PAGE_SIZE_BYTES` | `0x800` | 按芯片擦除页大小修改 |
| `OTA_SRAM_BASE_ADDRESS` | `0x20000000` | 按芯片 SRAM 起始地址修改 |
| `OTA_SRAM_SIZE_BYTES` | `64*1024` | 按芯片 SRAM 容量修改 |
| `OTA_BOOTLOADER_SIZE_BYTES` | `0x7000` | Bootloader 变大时同步修改链接脚本 |
| `OTA_METADATA_BASE_ADDRESS` | `0x08007000` | 必须紧接 Bootloader，且按页对齐 |
| `OTA_METADATA_SIZE_BYTES` | `0x1000` | 当前为两页元数据 |
| `OTA_SLOT_SIZE_BYTES` | `0x3C000` | 两个槽都必须能容纳升级 BIN |
| `OTA_SLOT_A_ADDRESS` | `0x08008000` | 按新的 Flash 分区修改 |
| `OTA_SLOT_B_ADDRESS` | `0x08044000` | 按新的 Flash 分区修改 |
| `OTA_UART_HANDLE` | `huart2` | 改成 CubeMX 生成的 UART 句柄 |
| `OTA_APPLICATION_SLOT` | A 或 B | A/B Target 分别定义 |
| `OTA_CURRENT_VERSION` | `v1.0.0` | 每次生成新固件必须递增 |

地址规则：Bootloader、元数据、A 槽、B 槽不能重叠；A/B 槽必须按 Flash 页对齐；BIN 大小必须小于等于 `OTA_SLOT_SIZE_BYTES`。

## ESP32：`esp32c3_arduino_gateway/ota_gateway_config.h`

必须填写 Wi-Fi SSID/密码、IoTDA endpoint、device_id、client_id、device secret、STM32 当前版本。GPIO6/GPIO7 和 115200 是本项目接线默认值，换线或换 UART 时才修改。

## 华为云固件包

- 升级类型：固件升级（FOTA），不是 ESP32 软件升级。
- 目标版本：与 `OTA_CURRENT_VERSION` 完全一致。
- 支持源版本：设备当前正在运行的版本。
- `custom_info`：严格写 `slot=A` 或 `slot=B`。
- 升级包：只能选择与目标槽一致的 BIN。
- SHA-256 和文件大小：使用实际 BIN 计算，不要手工填写估算值。
