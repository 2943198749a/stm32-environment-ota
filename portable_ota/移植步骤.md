# 从零移植 OTA

## 一、复制 STM32 核心

把 `stm32/ota_core/Inc` 加入 Keil 的 Include Paths，把 `stm32/ota_core/Src` 中的 C 文件加入应用 Target。不要只复制 `ota_app.c`，因为它还依赖元数据、SHA-256、Flash 存储和 UART 协议模块。

CubeMX 至少开启：GPIO、一个 UART（默认 USART2，115200 8N1）和 HAL。`ota_port.c` 使用 `OTA_UART_HANDLE` 读取/发送字节，换 UART 只改配置宏。

## 二、配置 A/B 链接地址

- Bootloader：`0x08000000`，最大 28 KB。
- 元数据：`0x08007000`，4 KB。
- Slot A：`0x08008000`，240 KB。
- Slot B：`0x08044000`，240 KB。

Slot A 和 Slot B 的应用必须分别使用自己的链接地址；否则向量表和中断会跳到错误位置。应用启动后设置 `SCB->VTOR`，再调用 `OtaApp_Init()` 和 `OtaUart_Init()`。

## 三、应用循环必须保留的代码

```c
OtaApp_Init();
OtaUart_Init(OTA_SLOT_A);       /* B Target 改成 OTA_SLOT_B */

while (1)
{
    OtaUart_Process();          /* 不断处理 ESP32 发来的控制行和二进制帧 */
    if (OtaApp_IsConfirmationRequired(OTA_SLOT_A) &&
        (HAL_GetTick() - bootTime >= 10000U))
    {
        if (OtaApp_ConfirmRunning(OTA_SLOT_A) == HAL_OK)
            send_boot_ok_to_gateway();
    }
}
```

`OtaUart_Process()` 不能只调用一次；它必须在主循环中持续调用。确认不能在下载完成瞬间执行，必须等新应用真正启动并稳定运行。

## 四、生成 A/B BIN

Keil 编译必须先确认 Target：A 使用 AppSlotA，B 使用 AppSlotB。AXF 转 BIN 示例：

```powershell
& 'C:\Keil_v5\ARM\ARMCLANG\bin\fromelf.exe' --bin `
  --output '.\app_slot_a_v1.2.1.bin' `
  '.\MDK-ARM\app_slot_a\app_slot_a.axf'
```

然后执行 `tools/check_ota_config.ps1` 检查槽位、版本、大小和 SHA-256。

## 五、配置 Arduino 网关

在 Arduino IDE 打开 `esp32c3_ota_gateway.ino`，安装 ESP32、PubSubClient、ArduinoJson 库。填写 `ota_gateway_config.h`，编译并下载到 ESP32-C3。ESP32 GPIO6 接 STM32 TX，GPIO7 接 STM32 RX，GND 必须共地，双方电平都为 3.3 V。

## 六、云端升级

设备必须先在线并上报 `version_report`。创建固件包时目标槽和 `custom_info` 要匹配。设备当前在 A 时只能发布 slot=B 的包；升级完成看到 `BOOT_OK` 后，云端才应显示 100%。

## 七、换成其他 MCU

先改 Flash/SRAM/页大小和 A/B 地址，再修改 Bootloader 的链接脚本、启动文件和 Flash 擦除实现。若 UART HAL API 不同，只改 `ota_port.c`，上层 `ota_app.c` 和 `ota_uart.c` 不需要改。
