# 工程技术手册设计

## 目标

在工程根目录新建 `工程说明.md`，将初学者可直接使用的工程说明与较详细的技术原理整合在同一份中文文档中。

## 读者

已经能使用 STM32CubeMX 和 Keil、但刚开始学习 HAL 与 FreeRTOS 的 STM32 初学者。

## 文档结构

1. 工程目标、主芯片与开发工具。
2. 外设、功能和引脚用途说明。
3. 目录结构：区分 CubeMX 生成代码、自写模块、FreeRTOS 和测试文件。
4. 快速使用：CubeMX 配置要点、编译、烧录和 LCD 预期页面。
5. FreeRTOS 三任务：每个任务的周期、职责、数据流与调用关系。
6. 共享环境数据：结构体副本、短临界区和避免任务竞争的原因。
7. 传感器技术细节：DHT11 单总线时序、BH1750 I2C、MQ135 ADC、有效标志和未接线行为。
8. LCD、按键和 ESP32 UART：局部刷新、30 ms 消抖、普通文本协议、零超时接收。
9. CubeMX 安全修改指南：`.ioc`、`KeepUserCode=true`、`USER CODE` 区、独立模块和重新生成后的检查清单。
10. 常用函数调用示例、排错清单与后续 OTA 扩展边界。

## 写作原则

- 文档只描述当前工程中已经实现的功能，不把 OTA、联网或云平台写成现有功能。
- 解释每个设计选择的原因和作用，而不只罗列文件名称。
- 给出短小的 C 调用示例，示例只使用当前公开 API。
- 说明 UART 仅是 STM32 与 Arduino ESP32 的普通文本通信。
- 明确未接传感器时会显示 `NO DATA`，不是故障数据。

## 验证

1. 检查文档涵盖三任务、三类传感器、LCD、按键、UART、CubeMX 保护和调试步骤。
2. 检查所有引用的函数名与当前头文件一致。
3. 检查没有把预留 OTA 页描述成已经可升级的功能。
